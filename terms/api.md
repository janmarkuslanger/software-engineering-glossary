An **Application Programming Interface** is the contract through which one component of software is used by another: the set of operations it offers, the data those
operations accept and return, and the guarantees around them.


## Why it matters

Every API that is published is a promise. Removing an operation, renaming a field or
tightening a validation rule is a breaking change for everyone who already depends on
it.
